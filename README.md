# Pattern Fit

A free browser-based tool for creating transparent Grid, Dots, and Stripes
patterns.

Adjust pattern spacing, size, thickness, color, layout, angle, and canvas
dimensions, then download the result as a transparent PNG.

Designed for use with Canva, Figma, PowerPoint, Google Slides, and other
design tools.

## Features

- Grid, Dots, and Stripes patterns
- Adjustable spacing and pattern size
- Custom colors
- Multiple dot layouts and stripe angles
- Preset and custom canvas sizes
- Transparent PNG export
- No sign-up required
- Images are generated locally in the browser

## Try Pattern Fit

[https://yukiko100.github.io/pattern-fit/](https://yukiko100.github.io/pattern-fit/)

## Privacy

Pattern Fit does not use analytics, advertising, tracking, or external
storage. Generated images are processed locally in the browser.
